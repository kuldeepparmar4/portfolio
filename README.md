## Tech Stack

This project is built using vanilla web technologies and integrated with modern third-party services:

- **Languages & Styling:** HTML5, CSS3, JavaScript (ES6+)
- **Form Services:** EmailJS (Handles contact form submissions directly from client-side JavaScript)
- **Deployment Platform:** Netlify

---

## Key Features

- **Responsive Design:** Completely optimized for a flawless experience across mobile, tablet, and desktop screens.
- **Smooth Scrolling:** Enhanced navigational user experience with intuitive internal link anchors.
- **Typing Animation Effect:** Dynamic role-switching typewriter simulation on the main hero section.
- **Contact Form Integration:** Fully functional direct messaging portal connected directly to my email server via EmailJS.
- **Resume Download Option:** Quick-access links to view or download my professional CV instantly.
